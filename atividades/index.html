Sobre o projeto

O Sistema de Gestão de Eventos é o projeto integrador desenvolvido pelos alunos da disciplina de Tecnologia Web. Ele reúne em um unico site, a divulgação e a inscrição em eventos promovidos pelo IFBA - Campus Paulo Afonso.

"Um site simples, feito somente com HTML, CSS e JavaScript, pode resolver um problema real da comunidade acadêmica"

Para saber mais, acesse o repositório do projeto ou entre em contato pelo email eventos@ifba.edu.br.
